# 福山思想百科

Francis Fukuyama 思想可视化百科 — 一个帮助读者系统了解福山思想脉络、核心著作与当代解释力的单页知识网站。

## 在线访问

部署后访问：`https://<你的用户名>.github.io/fukuyama-encyclopedia/`

## 内容

- 三阶段思想演化（宣告胜利 → 寻找根基 → 回望危机）
- 十部主要著作年表
- 十个核心概念解析
- 三支柱文明比较矩阵
- 六位同时代学者的思想对话
- 六条光谱轴线定位福山的思想坐标
- 当代政治现象的解释力分析
- 四条阅读路径推荐

## 技术

纯静态 HTML + CSS + 少量 JS，无需构建工具，直接部署到 GitHub Pages 即可。
